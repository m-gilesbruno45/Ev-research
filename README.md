# Torque — Automobile & EV Learning Guide

A responsive educational website created for **Maincrafts Technology Internship — Task 1: Automobile & Electric Vehicles**.

Torque explains automobile fundamentals and electric-vehicle systems in a clear, visual format for beginners and curious learners.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Automotive and EV fundamentals learning sections
- Interactive topic cards
- EV battery, inverter, and motor explanation
- ICE versus electric vehicle comparison
- Powertrain and ownership comparison modes
- Beginner-friendly learning path
- Accessible buttons, labels, and image descriptions
- Visual hierarchy, hover states, and responsive navigation

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons
- Pexels stock photography

## Run locally

1. Install Node.js LTS.
2. Open this project folder in Visual Studio Code.
3. Open the integrated terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address shown by Vite.

## Learning scope

The website introduces:

- Conventional internal-combustion powertrains
- Electric motors and instant torque
- EV battery packs and energy storage
- Inverters and power conversion
- Regenerative braking
- Charging versus refuelling
- Efficiency, maintenance, and tailpipe emissions
